# Example artifacts (mock mode)

Everything in this folder was **actually generated by Ledger** with the
deterministic offline mock provider (`make demo`, `make demo-fail`,
`ledger calibrate --mock`) against the bundled golden dataset and the
fictional Helios corpus.

**These numbers describe the mock heuristics, NOT the quality of any real
LLM.** They exist to show the exact shape of Ledger's outputs: report
structure, statistics fields, violation messages and calibration tables.

| File | Produced by | Shows |
|---|---|---|
| `comparison_pass_mock.md` / `.json` | `ledger demo` (baseline-v1 vs candidate-v2) | a PASS decision: near-zero delta, CI, per-category table |
| `comparison_fail_mock.md` / `.json` | `ledger demo --candidate-config configs/candidate_degraded.yaml` | a FAIL decision: significant regressions, critical failures, rule-by-rule violations |
| `calibration_mock.md` / `.json` | `ledger calibrate --mock` | judge-vs-human agreement metrics with the mock judge |

Regenerate equivalents at any time:

```bash
make demo && make demo-fail && make calibrate
```
